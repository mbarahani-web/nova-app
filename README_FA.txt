NOVA v61 — بستهٔ آماده‌سازی PWA

مبنای برنامه: NOVA v60 Planning Upgrade (فایل index.html بدون بازنویسی محتوای اصلی کپی شده است).
این بسته فایل‌های manifest.webmanifest، sw.js و آیکون NOVA را اضافه می‌کند تا ارجاع‌های PWA موجود در HTML به فایل‌های واقعی برسند.

نکتهٔ مهم:
- برای نصب PWA باید روی HTTPS یا localhost میزبانی شود؛ بازکردن مستقیم فایل HTML به‌تنهایی کافی نیست.
- این بسته روی گوشی یا سرور واقعی هنوز نصب/آزمایش نشده است.
- این مرحله اتصال هوش مصنوعی یا API key اضافه نمی‌کند.
- پیش از انتشار، باید آزمون مرورگر، مسیرهای ریشه، ذخیره‌سازی، و عملکرد آفلاین انجام شود.

برای میزبانی در ریشهٔ یک دامنه، محتویات همین پوشه را طوری آپلود کنید که index.html در مسیر / باشد.


به‌روزرسانی v62: آیکون PNG در اندازه‌های 192 و 512 اضافه شد؛ مانیفست و مسیرهای سرویس‌ورکر برای مسیر نسبی GitHub Pages تنظیم شدند. برای انتشار، فایل‌های داخل پوشه NOVA_v61_pwa را در ریشه مخزن جایگزین کنید.


v62.1 — آیکون با گوشهٔ نرم: nova-192.png و nova-512.png با گوشه‌های گرد و پس‌زمینهٔ شفاف (purpose=any)؛ nova-maskable-512.png تمام‌صفحه برای purpose=maskable. nova.svg قدیمی از مانیفست و سرویس‌ورکر حذف شد (فایل برای سازگاری در بسته می‌ماند). محتویات این بسته را مستقیماً در ریشهٔ مخزن آپلود کنید (نه داخل یک پوشه).
