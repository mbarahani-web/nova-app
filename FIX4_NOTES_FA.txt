v62.14 — ترجمهٔ فارسی رایگان و بدون کلید (Argos Translate)

چه شد
- build_news.py: اگر کلید ANTHROPIC_API_KEY نباشد، ترجمهٔ فارسی تیتر و خلاصه با کتابخانهٔ رایگان و متن‌باز Argos Translate (لیسانس MIT) داخل خود GitHub Actions انجام می‌شود. نیازی به تغییر فایل workflow نیست؛ اولین بار خودش pip install می‌کند.
- اگر کلید API باشد، همان ترجمهٔ Claude استفاده می‌شود (با خلاصهٔ روز). برای خاموش کردن ترجمهٔ رایگان: متغیر LOCAL_TRANSLATE=off.
- ترجمه‌هایی که قبلاً انجام شده‌اند (بر پایهٔ لینک خبر) دوباره ترجمه نمی‌شوند؛ پس روزهای بعد سریع‌تر است.
- هر خطایی در ترجمه نشریهٔ انگلیسی را متوقف نمی‌کند.

index.html (فقط بخش نشریه)
- در حالت فارسی، وقتی ترجمه ماشینی است، یک یادداشت کوچک می‌گوید «خودکار و ممکن است نادقیق باشد».
- صفحهٔ هر خبر، عنوان اصلی انگلیسی را زیر عنوان فارسی نشان می‌دهد تا بتوانید درستی ترجمه را بسنجید.
- اگر ترجمهٔ خودکار شکست بخورد، علتش در فوتر نشریه نوشته می‌شود («ترجمهٔ خودکار انجام نشد: ...»).

محدودیت‌ها (صادقانه)
- کیفیت ترجمه را هنوز ندیده‌ام. مدل رایگان معمولاً از Claude ضعیف‌تر است، به‌خصوص برای تیترهای کوتاه و اصطلاحات.
- خلاصهٔ روز (brief) با ترجمهٔ رایگان ساخته نمی‌شود؛ نوار سبز نمایش داده نمی‌شود.
- اولین اجرا چند دقیقه طول می‌کشد (نصب کتابخانه و مدل). نسخهٔ پایتون فعلی workflow ممکن است با کتابخانه سازگار نباشد؛ اگر شکست خورد، علتش در فوتر دیده می‌شود.
- تست‌ها با شبیه‌ساز API کتابخانه انجام شد (در محیط من نصب واقعی ممکن نبود).
